# 🤖 Unity 2D Robot Platformer Game

A 2D platformer game developed using **Unity** where the player controls a robot character and progresses through levels filled with enemies, traps, and interactive doors.

---

## 🎯 Game Overview

The main character is a **robot** that can:
- Move and jump across platforms
- Shoot projectiles at enemies
- Avoid dangerous traps such as rotating saws
- Enter doors to move between rooms and levels

The goal of the game is to **navigate each level safely**, defeat enemies, and reach the exit door to advance to the next level.

---

## ✨ Features

- 2D platformer movement (run & jump)
- Shooting system for the robot character
- Enemy patrol AI
- Trap system (saws)
- Door system (rooms & level transitions)
- Camera follows player between rooms
- Animator-based character and enemy animations

---

## 🎮 Controls

- **Move Left / Right:** A / D or Arrow Keys  
- **Jump:** Space  
- **Shoot:** Assigned attack key / mouse button

## 📁 Project Structure

- `Assets/` – Scripts, animations, prefabs, and scenes
- `ProjectSettings/` – Unity project settings
- `Packages/` – Unity packages

---

## ▶ How to Run the Project

1. Clone the repository
2. Open **Unity Hub**
3. Click **Open Project** and select the project folder
4. Open the main scene
5. Press **Play**
